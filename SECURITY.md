# Security Policy

This is an educational project that demonstrates secure authentication in PHP
(CSRF protection, session hardening, brute-force lockout). It is not intended
for production use.

## Reporting a vulnerability

If you find a security issue, please **do not open a public issue**.
Report it privately through the contact options on
[mattheusalfonso.github.io](https://mattheusalfonso.github.io) (LinkedIn or WhatsApp).

Please include:

- a description of the issue and its impact;
- steps to reproduce (request, payload, expected vs. actual result);
- the file and line, if you know them.

I will acknowledge the report within 7 days and credit you in the fix,
unless you prefer to stay anonymous.

## Scope

In scope: the code in this repository (`login.php`, `security.php`,
`dashboard.php`, `logout.php`, `index.php`, `config.php`).

Out of scope: the demo credentials shown on the login page. They are public
on purpose, for testing.
